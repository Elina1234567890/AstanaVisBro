# AstanaVis Bro — резервная копия

Источник: https://platform.idosgames.com/1ZPS8DLV/ai-coding (DEV workspace).

- `initial-2026-10-07/` — исходный снимок: 81 файл редактора и конфигурации title PROD/DEV. Не обновлять и не перезаписывать.
- `current/` — актуальная копия. Обновлять после каждого завершённого изменения исходников или конфигурации в этом чате. Новые файлы добавлять; удалённые убирать только из current, сохраняя предыдущий снимок.
- `source-manifest.json` — исходный перечень файлов с SHA-256 и размерами.
- `astanavis-initial-2026-10-07.zip` — архив исходного снимка.

Перед последующими изменениями сохранять затрагиваемые файлы из current в отдельный снимок `snapshots/<timestamp>/`. После изменения сверять current с облачным редактором и обновлять манифест актуальной копии.

Исходники прочитаны через редактор, без подмены стандартными файлами из каталога. UTF-8; окончания строк получены через буфер обмена редактора и могут отличаться от серверного байтового представления. Конфигурации title находятся здесь только для восстановления: приложение не должно импортировать эти JSON или использовать их как локальную экономику.

Эта копия не содержит аккаунты игроков, их инвентари, установленные npm-пакеты и содержимое внешних CDN. SDK восстанавливается по закреплённым версиям package.json. Фоновой синхронизации нет: актуальную копию обновляет агент при работе над проектом.
