# Roadmap

## Milestone 1 — Shared game hub

- [x] iDos Games client and App Shell integration
- [x] Sign-in, session restoration and access screen
- [x] Responsive lobby and mode navigation
- [x] Shared profile, VIS presentation, store and collections
- [x] Global theme, motion and sound configuration

## Milestone 2 — Orb Merge

- [ ] Define the board, spawn rules and three-touch merge algorithm
- [ ] Implement input, animation and deterministic scoring
- [ ] Add run lifecycle, pause/restart and result presentation
- [ ] Connect validated results to shared progression
- [ ] Add unit and interaction tests

## Milestone 3 — Color Flow

- [ ] Define flask capacity, legal pours and level format
- [ ] Implement level rendering, input and undo
- [ ] Add win detection, scoring and progression rewards
- [ ] Add curated levels and tests

## Milestone 4 — Cake Sort

- [ ] Define piece movement and cake-completion rules
- [ ] Implement levels, input and win detection
- [ ] Add scoring, rewards and tests

## Milestone 5 — Release readiness

- [ ] Add end-to-end smoke tests for sign-in, lobby and each mode
- [ ] Measure loading performance and split large optional bundles
- [ ] Add a current product screenshot and public demo link
- [ ] Complete accessibility and mobile-device review
- [ ] Choose and publish an open-source license if public reuse is intended
